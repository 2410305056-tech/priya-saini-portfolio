# Priya Saini — Forensic Science Portfolio

Static personal portfolio for **Priya Saini**, B.Sc. Forensic Science student at Geeta University, Panipat.

`index.html` is at the repository root so Vercel can serve it as a static site.

## Local preview

Open `index.html` in a browser, or from this folder:

```bash
npx --yes serve .
```

## Live site

Public Vercel URL: https://priya-saini-portfolio-teal.vercel.app/

GitHub: https://github.com/2410305056-tech/priya-saini-portfolio

## Deploy

1. Push this repository to GitHub.
2. Import it in Vercel as a static / Other project.
3. Leave the build command empty.
4. Deploy and use the public `.vercel.app` URL.
